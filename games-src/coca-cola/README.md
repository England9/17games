# Coca-Cola Refresh Rush

A kawaii, Coca-Cola–themed Fruit Ninja–style browser game. Swipe or shoot flying trash, recycle empty Coke bottles, grab power-ups, and avoid bombs in a 60-second rush.

## Play

```bash
npm install
npm run dev
```

Open **http://127.0.0.1:47321**

## Controls

- **Mouse / touch:** click or hold to shoot soda pellets toward the pointer
- **Swipe / drag:** slice trash and bottles like Fruit Ninja
- **Empty bottles** fly into the recycling machine for bonus points
- **Coca-Cola** bottle → faster shooting
- **Coke Zero** bottle → +5 seconds
- **Bombs** → big score penalty (don’t hit them!)
